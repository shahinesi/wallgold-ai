# معماری دستیار وال‌گلد

```text
ChatGPT / Codex
      │
      ├── داده تازه وب: خبر، اقتصاد کلان، طلای جهانی، ارز
      │
      ▼
مهارت‌های فارسی
      │
      ▼
MCP Server
  ├─ رابط WallGold: بازار، موجودی، قیمت قابل معامله، وضعیت سفارش
  ├─ موتور تصمیم: وزن‌دهی + تازگی + پوشش + اختلاف شواهد
  ├─ موتور تکنیکال
  ├─ سیاست خزانه و موتور ریسک
  ├─ پیش‌نمایش معامله با توکن امضاشده و کوتاه‌عمر
  ├─ بازمتعادل‌سازی پرتفوی
  ├─ خرید دوره‌ای و برنامه‌های شرطی
  ├─ قوانین هشدار و ارزیابی آن‌ها
  ├─ تاریخچه تحلیل و قیمت‌های قابل معامله
  ├─ معامله آزمایشی
  └─ بک‌تست

مسیر خصوصی اجرای واقعی:
پیش‌نمایش → تأیید آگاهانه → قیمت تازه → موجودی تازه → سیاست ریسک → سقف ۲۴ساعته → سفارش → ثبت ممیزی
```

## اصول طراحی

- **تحلیل** از **اجرای معامله** جداست.
- درصد اطمینان در موتور تصمیم محاسبه می‌شود و مدل زبانی اجازه ندارد آن را از روی حدس بسازد.
- قبل از هر پیش‌نمایش، قیمت قابل معامله تازه گرفته می‌شود.
- پیش‌نمایش سفارش ثبت نمی‌کند و با HMAC امضا می‌شود.
- اجرای خصوصی دوباره قیمت، موجودی، سیاست ریسک و سقف ۲۴ ساعت اخیر را بررسی می‌کند.
- توکن پیش‌نمایش پس از یک اجرای ثبت‌شده قابل استفاده مجدد نیست.
- حالت پیش‌فرض سیاست «مشاور» است و اجازه اجرای واقعی نمی‌دهد.
- تمام متن‌هایی که کاربر می‌بیند فارسی طراحی شده‌اند؛ نام فنی ابزارها برای قرارداد برنامه‌نویسی انگلیسی مانده است.
