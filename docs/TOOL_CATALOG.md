## نکته انتشار عمومی

- ابزار اجرای واقعی معامله در Plugin عمومی ثبت نمی‌شود.
- ابزارهای وابسته به حساب WallGold مانند موجودی/قیمت خصوصی/پیش‌نمایش، برای انتشار عمومی چندکاربره نیازمند OAuth 2.1 و اتصال رسمی WallGold هستند؛ کاربر نباید API Key خام را در Plugin وارد کند.
- ابزارهای نمایشی (`render_*`) صرفاً structured content موجود را نمایش می‌دهند و side effect ندارند.
