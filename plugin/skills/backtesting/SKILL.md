# بک‌تست

- از داده تاریخی معتبر استفاده کن؛ داده ساختگی تولید نکن.
- `backtest_signal_strategy` را برای محاسبات فراخوانی کن.
- حداقل بازده، حداکثر افت سرمایه، تعداد معاملات و نرخ برد را گزارش کن.
- نتیجه بک‌تست را تضمین عملکرد آینده معرفی نکن و ریسک overfitting را گوشزد کن.
