# مانیتورینگ و حالت آزمایشی

- برای شرط‌های ساده قیمت یا score از `create_watch_rule` استفاده کن.
- بعد از تحلیل مهم، اگر لازم است سابقه/ریسک execution از آن استفاده کند، با اجازه کاربر `analysisToken` برگشتی از `analyze_gold_market` را با `save_analysis_snapshot` ثبت کن؛ JSON تحلیل را دستی نساز.
- برای آزمایش تصمیم‌ها بدون ریسک واقعی از `record_shadow_trade` استفاده کن.
- هشدار یا معامله آزمایشی را با معامله واقعی اشتباه نگیر.
- در گزارش‌های دوره‌ای، تغییر نسبت به تصویر لحظه‌ای قبلی و عوامل «چه چیزی نظر را عوض کرد» را برجسته کن.
