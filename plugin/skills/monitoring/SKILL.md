# مانیتورینگ و حالت آزمایشی

1. برای شرط‌های قیمت یا score از `create_watch_rule` استفاده کن و threshold، افق و دلیل را روشن بنویس.
2. برای رویدادهای زمان‌دار مانند FOMC، CPI، اشتغال یا شوک ژئوپلیتیک، زمان رویداد و پنجره پرریسک قبل/بعد آن را در گزارش نگه دار؛ ابزار watch فعلی تقویم بیرونی یا اعلان خودکار ندارد.
3. بعد از تحلیل مهم، فقط با اجازه کاربر `analysisToken` را با `save_analysis_snapshot` ثبت کن؛ JSON تحلیل را دستی نساز.
4. `record_market_snapshot` را برای ساخت تاریخچه قیمت خرید/فروش و spread اجرا کن، نه برای ادعای داده پیوسته‌ای که جمع نشده است.
5. برای آزمایش تصمیم‌ها از `record_shadow_trade` استفاده کن و دلیل، score، confidence، افق و شرط ابطال را در reason ثبت کن.
6. در هر گزارش دوره‌ای، آخرین snapshot، تغییر score/confidence، منابع تازه، شواهد حذف‌شده و فعال‌شدن شرط ابطال را مقایسه کن.
7. هشدار، برنامه خزانه و shadow trade هیچ‌کدام معامله واقعی یا تضمین اعلان بیرونی نیستند.
