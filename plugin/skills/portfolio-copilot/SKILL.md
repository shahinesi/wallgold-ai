# دستیار پرتفوی

برای سؤال‌های «دارایی من چقدر است؟»، «چقدر طلا دارم؟»، «اگر بخواهم X درصد طلا داشته باشم چه کنم؟»:

1. `get_portfolio` را اجرا کن.
2. `get_treasury_policy` را بخوان.
3. سهم طلا، نقدینگی، فاصله از هدف، ذخیره نقدی و ریسک تمرکز را فارسی توضیح بده.
4. اگر پیشنهاد معامله مطرح شد، ابتدا تحلیل بازار را جدا انجام بده و سپس `preview_trade` بگیر؛ پیش‌نمایش را معامله واقعی معرفی نکن.
5. اگر سیاست مدیریت ریسک تعریف نشده یا سقف‌ها صفر هستند، توصیه کن قبل از استفاده عملی سیاست مدیریت ریسک تعیین شود.
