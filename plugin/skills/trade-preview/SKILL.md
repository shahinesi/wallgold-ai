# پیش‌نمایش معامله

1. برای کاربرانی که می‌خواهند بدانند «اگر X تومان بخرم/بفروشم چه می‌شود؟»، `preview_trade` را اجرا کن.
2. مبلغ، گرم، قیمت هر گرم، زمان انقضای قیمت قابل معامله، موجودی قبل/بعد، سهم طلا بعد و نتیجه کنترل سیاست مدیریت ریسک را فارسی نشان بده.
3. تأکید کن این ابزار سفارش ثبت نکرده است.
4. نسخه عمومی Plugin نباید ابزار اجرای معامله سرمایه‌گذاری را فراخوانی یا پیشنهاد کند.
5. اگر کاربر اجرای واقعی را می‌خواهد، توضیح بده که اجرای خصوصی خارج از Plugin عمومی و با کنترل‌های جداگانه انجام می‌شود.
