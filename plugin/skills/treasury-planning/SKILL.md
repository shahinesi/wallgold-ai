# برنامه‌ریزی خزانه طلا

- برای سؤال «چقدر بخرم یا بفروشم تا سهم طلا به هدف برسد؟» از `preview_rebalance` استفاده کن.
- برای برنامه خرید دوره‌ای یا قوانین شرطی از `create_treasury_plan` استفاده کن؛ ثبت برنامه به معنی اجرای معامله نیست.
- برای نمای یکپارچه دارایی، سیاست ریسک، آخرین تحلیل و قوانین هشدار از `get_gold_cfo_brief` استفاده کن.
- مبلغ پیشنهادی را همیشه با ذخیره نقدی، سقف معامله و سهم حداکثری طلا مقایسه کن.
- نتیجه را کاملاً فارسی گزارش کن و بین «پیشنهاد»، «پیش‌نمایش» و «معامله واقعی» تمایز روشن بگذار.
